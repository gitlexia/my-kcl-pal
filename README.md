# MyKCLPal — Health & Wellness Management Prototype

MyKCLPal is a mobile application prototype developed as part of a Human–Computer Interaction project at King’s College London. The system was designed to support users in maintaining healthy lifestyles by integrating exercise tracking, diet management, budgeting awareness, and community motivation into a single unified platform.

The project followed a full user-centred design workflow — from qualitative research and data analysis to interaction design and high-fidelity prototyping in Figma.

Project Goals

The primary objective of MyKCLPal was to design a flexible and intuitive wellness application that helps users stay consistent with health goals despite time, financial, or motivational constraints.

Key goals included:

Supporting habit consistency rather than short-term tracking

Reducing cognitive load through clear visual feedback and simple interactions

Integrating multiple wellness domains into one cohesive experience

Encouraging motivation through social accountability and personalised insights

These goals were informed by extensive user research involving 45 semi-structured interviews across different demographics .

Key Features
Personalised Onboarding

Users complete a short questionnaire that tailors recommendations based on exercise preferences, dietary needs, and financial constraints.

Planner & Daily Tasks

A flexible daily planning interface helps users organise wellness activities based on energy level and schedule variability.

Exercise Tracking & Insights

Users can log workouts, explore new routines, and view weekly visualisations of activity patterns to support behavioural awareness.

Diet & Nutrition Monitoring

The system provides calorie tracking, macronutrient breakdowns, hydration logging, and structured dietary plan support.

Budget Tracking

Health-related spending is visualised through simplified charts and categorized expense tracking to promote financial awareness.

Community Motivation

Users can connect with friends, share progress, and participate in daily challenges to improve accountability and engagement.

AI Chatbot Support

A conversational interface provides guidance across wellness domains and enables quick access to personalised advice.

Design Process

The application was developed using a structured human-centred design approach:

Empathise — Conducted qualitative interviews and coded responses to identify behavioural patterns and pain points

Define — Synthesised findings into personas and a unified design problem statement

Ideate — Generated feature concepts using methods such as the How-Now-Wow matrix

Prototype — Designed interaction flows and mobile UI screens in Figma

Evaluate — Iterated on visual hierarchy, usability, and task accessibility

This process ensured that all features were grounded in real user needs rather than assumptions.
